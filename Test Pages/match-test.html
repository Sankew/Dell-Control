How to use: open the MacBook lid, open this file on both screens (or drag the window across), and set both to similar brightness by matching the white bar. Then compare each section. Colours are drawn with CSS colour management, so each screen shows them through its own macOS display profile.

1 · White point (should look the same white, neither bluer nor greener)

#FFFFFF

2 · Shadow steps on black (count how many squares you can see; both screens should agree)

3 · Grey ramp (should be neutral with no tint, and even steps)

4 · ColorChecker-style patches (sRGB)

5 · Skin tones (sRGB)

6 · Saturated colours: sRGB vs Display P3 (top = sRGB limit, bottom = P3 limit; the Dell only reaches ~82% of P3, so its bottom row will look slightly less vivid than the MacBook's)
